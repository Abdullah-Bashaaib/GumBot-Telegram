## ✨ المميزات

- 🕒 **ثلاث نشرات يومية** – صباحًا، ظهرًا، ومساءً بتوقيت مكة المكرمة.
- ✅ **أحاديث صحيحة وحسنة فقط** – يتم تجاهل الأحاديث الضعيفة تلقائيًا.
- 📖 **مصدر موثوق** – يجلب الأحاديث من [UmmahAPI](https://ummahapi.com) مع ترجمة المصدر والحكم للعربية.
- 🎨 **تنسيق اقتباس جذاب** – عرض الحديث داخل اقتباس تيليجرام أنيق، مع أيقونات ومعلومات كاملة.
- 🤖 **تشغيل آلي بالكامل** – يعمل عبر GitHub Actions دون تدخل يدوي.
- 🔒 **آمن ومخفي** – التوكن والمعلومات الحساسة تُخزن كمتغيرات سرية (Secrets).

## 🚀 خطوات الإعداد

### 1. المتطلبات الأساسية

- **حساب GitHub** لرفع المشروع وتشغيل Actions.
- **بوت تيليقرام**: أنشئ بوتًا عبر [@BotFather](https://t.me/BotFather) واحصل على التوكن.
- **قناة تيليقرام**: أنشئ قناة واجعل البوت مشرفًا فيها، واحصل على معرف القناة (مثل `@my_channel`).

### 2. إعداد المستودع

1. ارفع جميع الملفات إلى مستودع GitHub (عام أو خاص).
2. اذهب إلى **Settings > Secrets and variables > Actions**.
3. أضف السرين التاليين:
   - `BOT_TOKEN`: توكن البوت من BotFather.
   - `CHANNEL_ID`: معرف القناة (مثل `@my_channel` أو `-1001234567890`).

### 3. تشغيل البوت

- فور إضافة الأسرار، ستعمل GitHub Actions تلقائيًا حسب الجدول.
- يمكنك تجربة التشغيل اليدوي: اذهب إلى تبويب **Actions**، اختر workflow، واضغط **Run workflow**.
